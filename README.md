# Nanu's Recipe Book

**OSTAD DevOps Git Assignment**

## Project Overview

This repository contains my OSTAD DevOps Git assignment, *Nanu's Recipe Book*. The project demonstrates fundamental Git version control operations through recipe files and practical exercises.

## Assignment Chapters

### Chapter 1: The First Recipe
- Initialized a Git repository using `git init`.
- Created and staged `bhapa-pitha.md`.
- Practiced `git diff` and `git diff --staged`.
- Created a meaningful commit.
- Practiced unstaging a file using `git reset`.

### Chapter 2: The Secret Spice
- Created a `.gitignore` file.
- Added rules to ignore secret and temporary files.
- Verified ignored files using `git status --short` and `git status --ignored`.
- Committed the `.gitignore` file.

### Chapter 3: Git Branching and Merging
- Created the `eid-special` branch.
- Added an Eid special recipe and serving tips.
- Created commits on the feature branch.
- Merged `eid-special` into `master`.
- Verified the commit history.
